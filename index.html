Feishu integration

Mirror invite codes to a Feishu Bitable and manage them from a Feishu bot.

Checking configuration…

Setup instructions
  1. Create a Feishu custom app and enable bitable:app, im:message, and im:message:send_as_bot.
  2. Create a Bitable table with text fields Code, Status, Note, Expires, MaxUses, UsedCount.
  3. Add env vars: FEISHU_APP_ID, FEISHU_APP_SECRET, FEISHU_BITABLE_APP_TOKEN, FEISHU_TABLE_ID, FEISHU_VERIFICATION_TOKEN, FEISHU_ADMIN_OPEN_IDS.
  4. Point the app's event subscription to /api/feishu/event and subscribe to im.message.receive_v1.
  5. Bot commands: list, new [days] [uses] [note], revoke CODE, stats, help.
